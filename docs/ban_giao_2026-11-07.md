## 1. Dựng lại trên máy mới
```
git clone https://github.com/MrSooo/KLTN.git kltn
cd kltn
git switch v2-lao-dong
```
Trên máy cũ remote tên là `KLTN`; clone mới sẽ gọi nó là `origin`. Nhánh `main` còn ở bản rất cũ, chưa quyết gộp. Nhánh `refactor` là v1 đóng băng; commit `25c65e6` (mốc v1) nằm trong lịch sử của `v2-lao-dong` nên xem lại v1 bằng `git switch --detach 25c65e6`.

Python: máy cũ dùng **3.14.5**. Code chỉ dùng thư viện chuẩn, các Python 3 khác chưa kiểm. Chỉ khi chạy `--llm live` mới cần venv:
```
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install google-genai==2.34.0
```
Chưa cần cho L0-L5. (Windows; máy khác hệ điều hành thì đổi `Scripts` thành `bin`.)

## 8. Bẫy kỹ thuật
- Máy cũ `core.autocrlf=true`: sau khi chạy code, `git status` có thể hiện file M giả (LF/CRLF). Xem `git diff` trước khi `git restore`. Dữ liệu `data/raw/labor/` luôn LF; code không được giả định `\r\n`.
- Chạy script: `python -I src/<file>.py <đường dẫn>` (cờ `-I`). Test: `python -I tests/test_aN.py`, dòng cuối `tổng test lỗi: 0`.
